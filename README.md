# Nova Bot

Бот-помощник для учителей в мессенджере MAX. Написан на Python с использованием библиотеки [aiomax](https://pypi.org/project/aiomax/), запускается в Docker.

## Возможности

| Команда | Что делает |
|---|---|
| `/game` | Собирает презентацию-викторину из вопросов и ответов и присылает готовый `.pptx` |
| `/random` | Случайно разбивает список людей на группы |
| `/reshuffle` | Перемешивает тех же людей по тем же группам |
| `/ai` | Задать вопрос ИИ-помощнику «Алиса» |
| `/help` | Список команд |
| `/cancel` | Отменить текущее действие |

### /game - презентация из вопросов и ответов

1. Отправьте `/game` (или `/game 5`, чтобы задать число пар; по умолчанию 9).
2. Бот по очереди запросит вопрос и ответ для каждой пары.
3. В конце бот подставит тексты в шаблон `template.pptx` и пришлёт готовый файл.

Требования к шаблону: первый слайд титульный, на слайдах со 2-го находятся надписи-заготовки `ТЕКСТ ВОПРОСА` и `ТЕКСТ ОТВЕТА`. Пара 1 попадает на слайд 2, пара 2 - на слайд 3 и так далее. Неиспользованные слайды удаляются.

### /random - разбивка на группы

1. Отправьте `/random`.
2. Пришлите список людей: `1.Петр Иванов 2.Иван Жук 3.Маша Петрова`, через запятую или по одному в строке.
3. Пришлите названия групп (`1.Красные 2.Синие`) или просто число групп (`3` - будут «Группа 1», «Группа 2», «Группа 3»).

Размеры групп отличаются не более чем на одного человека. Команда `/reshuffle` даёт другой состав тех же групп.

### /ai - ИИ-помощник

- `/ai Что такое фотосинтез?` - разовый ответ.
- `/ai` - режим диалога, бот отвечает на каждое сообщение до команды `/cancel`.

## Запуск в Docker

1. В файле `TOKEN.env` рядом с `Dockerfile` вместо токена стоит символ `*`:
   ```
   BOT_TOKEN=*
   ```
   **Замените `*` на токен бота** , без кавычек и пробелов (изначально токен удален из файла в целях безопасности). Файл копируется в образ при сборке, поэтому менять его нужно до шага 2.

2. Соберите образ:
   ```
   docker build -t nova-bot .
   ```

3. Запустите контейнер:
   ```
   docker run -d --name nova-bot --restart unless-stopped nova-bot
   ```
   Или в Docker Desktop: вкладка Images, у образа `nova-bot` нажать Run.

Логи: `docker logs -f nova-bot`. Остановка: `docker stop nova-bot`.

## Запуск без Docker

```
pip install -r requirements.txt
python osnova.py
```

Токен читается из файла `TOKEN.env` рядом с `osnova.py` или из переменной окружения `BOT_TOKEN`.

## Структура проекта

```
osnova.py          - код бота
template.pptx      - шаблон презентации для /game
requirements.txt   - зависимости Python
Dockerfile         - сборка образа (включает сертификаты Минцифры для MAX)
TOKEN.env          - файл с токеном (вместо * вставьте токен бота)
```

## Как добавить новую функцию

В `osnova.py` достаточно написать функцию и зарегистрировать её декоратором:

```python
@command("/hello", "Поздороваться")
async def hello(message, args):
    await message.send("Привет!")
```

Для диалога из нескольких шагов используется `set_state(user_id, обработчик, данные)` - пример смотрите в реализации `/random`.

## Безопасность

В репозитории токен заменён на `*`. Свой токен вставляйте только в локальную копию файла `TOKEN.env`. Токен копируется в образ при сборке, поэтому собранный образ (`docker save`, публикация в Docker Hub) с настоящим токеном публиковать нельзя.
